# RosterReciter — 架構與開發環境筆記

## 專案定位
報菜名遊戲投影片生成器。Flask + Pillow 後端，純 Vanilla JS 前端，單機本地使用。

## 技術棧
- Python 3.10 (py launcher: `py -3.10`)
- Flask 3.0.3 + Werkzeug 3.1.8
- Pillow 10.4.0（圖片合成）
- 無前端 build step，無測試框架

## venv 狀態（重要）
`venv/Scripts/python.exe` **不存在**（venv 在其他機器建立，Python 路徑為 `C:\Users\eija.wu\AppData\Local\Programs\Python\Python310`）。
**重建指令：**
```
rmdir /s /q venv
py -3.10 -m venv venv
venv\Scripts\pip install -r requirements.txt
```

## 啟動方式
```
venv\Scripts\python.exe app.py
# 或啟動 venv 後：python app.py
```
→ http://localhost:5000

## 核心資料流
1. 使用者在瀏覽器設定玩家資料夾、上傳資源
2. `/api/scan` 掃描角色清單（以第一位玩家資料夾為基準）
3. `/api/preview` 或 `/api/generate` 呼叫 `compose_slide()`
4. Pillow 合成：背景 → 角色圖（cover 裁切）→ 頭像 → 名字框 → 標題
5. 批量生成打包為 `output.zip` 下載

## 版面設定持久化
- `config/default_layout.json` — 出廠預設（重設時覆寫）
- `config/layout.json` — 使用者目前版面（自動儲存，gitignore）
- `config/session.json` — 上次工作階段（玩家資料夾、角色選取等）

## 常見陷阱
- 中文標題需設定 `font_path`（如 `C:/Windows/Fonts/msjh.ttc`）
- `/api/browse/folder` 使用 tkinter，需 GUI 環境
- `output/` 每次批量生成前會被 `shutil.rmtree` 清空
- 上傳限制 50MB（`MAX_CONTENT_LENGTH`）
